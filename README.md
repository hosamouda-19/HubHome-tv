# HubHome — Launcher لـ Android TV بأسلوب Samsung Smart Hub

> **حالة المشروع: كُتب بالكامل لكنه لم يُبنَ ولم يُختبر.**
> بيئة العمل التي كُتب فيها لا تصل إلى مستودعات Google/Maven ولا يوجد فيها Android SDK،
> لذلك لم يُنتج APK ولم يُشغَّل على محاكي أو تلفزيون. لا توجد أي أرقام أداء أو ذاكرة مقاسة.
> قد تظهر أخطاء ترجمة بسيطة في أول بناء.

## ما الذي يفعله
- شريط جانبي (الرئيسية / التطبيقات / وضع الساعة / الإعدادات) يتوسع عند التركيز ويُظهر الأسماء.
- الرئيسية: صف المفضلة (+ بطاقة «إضافة تطبيقات»)، المفتوحة مؤخرًا، مصادر الإدخال (HDMI… إن أتاحها النظام)، وساعة وتاريخ.
- التطبيقات: شبكة بكل التطبيقات القابلة للتشغيل، تُبنى عند أول فتح.
- ضغطة مطوّلة على Select أو زر Menu على أي تطبيق: فتح، إضافة/إزالة من المفضلة، تحريك يمين/يسار، معلومات التطبيق، إلغاء التثبيت.
- الإعدادات (تُحفظ محليًا): الخلفية (6 تدرجات)، صيغة الساعة، إظهار «مؤخرًا» والمصادر، حركة التركيز، إعادة ضبط المفضلة، فتح إعدادات الشاشة الرئيسية والنظام.
- يتحدث تلقائيًا عند تثبيت/حذف تطبيق.

## قرارات الأداء (جهاز 1GB RAM / Mali-450)
- Views أصلية فقط، بلا Compose ولا Leanback ولا أي مكتبة خارجية.
- خلفيات تدرّج لوني مرسومة بالكود: بلا صور ولا ضبابية ولا فيديو ولا حركة مستمرة.
- التركيز: تكبير 1.12× وإطار بـ transform فقط (110ms)، ويمكن إيقافه من الإعدادات.
- أيقونات بحجم ثابت في خيط واحد، وذاكرة مؤقتة 48 أيقونة، وتفريغها عند `onTrimMemory`.
- لا خدمات خلفية ولا شبكة؛ كل شيء يعمل دون إنترنت.

## البناء
1. افتح المجلد في Android Studio (Koala أو أحدث) ودعه ينزّل Gradle وSDK 34.
2. `Build > Build APK(s)`، أو من الطرفية: `./gradlew assembleRelease`
3. الناتج: `app/build/outputs/apk/release/app-release.apk` (موقّع بمفتاح debug ليُثبَّت مباشرة).
> `targetSdk = 31` (Android 12) عمدًا لتطابق جهازك.

## التثبيت على التلفزيون
```
adb connect <TV_IP>:5555
adb install -r app-release.apk
```
(أو من فلاش USB بمدير ملفات). فعّل «خيارات المطور» وتصحيح USB/ADB عبر الشبكة.

## تعيينه الشاشة الرئيسية
التطبيق يعلن `HOME` + `DEFAULT`، لكن **القرار للبرنامج الثابت للجهاز**:
1. من الإعدادات داخل HubHome اختر «تطبيق الشاشة الرئيسية»، أو افتح إعدادات النظام > التطبيقات > التطبيقات الافتراضية.
2. أو اضغط زر Home في الريموت؛ قد يعرض النظام نافذة اختيار Launcher (اختر HubHome > دائمًا).
3. إن لم يوجد خيار كهذا (شائع في أجهزة الشركات الصينية)، فالـ Launcher الأصلي مقفول، وستفتح HubHome يدويًا من قائمة التطبيقات. لا حل بدون Root أو تعديل النظام، ولا أنصح به.
استعادة الأصلي: إعدادات > التطبيقات > HubHome > مسح الإعدادات الافتراضية.

## الاختبار على اللابتوب (محاكي)
Android Studio > Device Manager > Create Device > **TV** > اختر مثلًا `Television (1080p)` ثم `Television (720p)` وصورة نظام **API 31** (Android 12). شغّل التطبيق وتنقّل بأسهم الكيبورد وEnter (Select) وEsc (Back).
للتأكد من المعايرة اجرب أيضًا: `adb shell wm size 1280x720` و`adb shell wm density 160` (والعودة بـ `wm size reset` و`wm density reset`). الواجهة تُحسب من دقة الشاشة بالبكسل فيجب أن تبقى النسب واحدة.
المحاكي لا يصلح لقياس الأداء على جهاز 1GB RAM.

## قيود معروفة
- «المفتوحة مؤخرًا» تسجّل ما فُتح من HubHome فقط (UsageStats يحتاج صلاحية خاصة).
- مصادر الإدخال تعتمد على TvInputManager؛ قد لا تعمل أو لا تظهر على أجهزة غير معتمدة من Google.
- تطبيق واحد لكل حزمة (نشاط الإطلاق الأول).
- لا خلفيات صور مخصصة بعد.
- التصميم مستوحى من الأسلوب العام لـ Smart Hub (شريط جانبي يسارًا، صفوف أفقية، تركيز بإطار أبيض). لم تُجرَ مقارنة بصرية دقيقة بلقطات مرجعية، فلا أدّعي التطابق. بلا أصول سامسونج، والأيقونة والبانر أصليان مؤقتان.

## ما يجب اختباره على الجهاز
بدء التشغيل، سلاسة التنقل، زر Home، العودة من تطبيق آخر، الذاكرة (`adb shell dumpsys meminfo app.hubhome.launcher`)، وظهور الواجهة بدقة التلفزيون الفعلية.

## CleanFrame
مشروع Tizen (HTML/JS لـ Samsung The Frame) بترخيص MIT؛ لا يعمل على Android، ولم يُنقل منه كود، واقتُبست أفكار الأداء فقط.
